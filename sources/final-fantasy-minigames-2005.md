# Final Fantasy Minigames

## Square Enix Mobile (Publisher)

- https://web.archive.org/web/20090830052615/http://www.square-enix.co.jp/mobile/sem/flash_ranking/index.html -- Bombs' Great Counterattack, Cactuar Panic, Moogle's Shop Manager for a Day, Free-Diving Moogle's Undersea Expedition: titles*, dates*, platforms*, titleUrl* (Square Enix Mobile site, ranking-enabled Flash games page; capture of 2009-08-30) -- accessed 2026-10-24
  - Nine free Flash games with a weekly ranking and an all-time high-score ranking; copyright 2008 Square Enix on all nine; no release dates, carriers or English titles stated; the English titles are ours (literal)
  - ボムの大逆襲 (anchor #bom): the Bombs counterattack; the Chocobo changes job to Black Mage and answers with Blizzard
  - サボテンダーパニック (#sabo_panic): Cactuar comes to steal the Gysahl vegetables the Chocobo loves
  - モーグリの一日店長 (#mogu_tencho): a Moogle's shop, ring up customers fast; the blurb mentions the Chocobo only in an idiom ("busy enough to want even a Chocobo's hand")
  - 素モーグリの海底探検 (#sumoguri): a Moogle's seabed treasure hunt ("kupo"); 素モーグリ plays on 素潜り (free diving)
  - The other five on the page have Chocobo in the title and are in [chocobo-game-series-1997.md](chocobo-game-series-1997.md)
  - Release window, from the site's menu captures: the 2008-07-06 menu lists none of the nine (https://web.archive.org/web/20080706054924/http://www.square-enix.co.jp/mobile/sem/); the 2008-09-17 menu lists seven, including all four above (https://web.archive.org/web/20080917031959/http://www.square-enix.co.jp/mobile/sem/); the 2009-01-22 menu lists all nine (https://web.archive.org/web/20090122231957/http://www.square-enix.co.jp/mobile/sem/)
  - Only capture of the ranking page before 2009: 2008-09-18 (https://web.archive.org/web/20080918073450/http://www.square-enix.co.jp/mobile/sem/flash_ranking/index.html)
  - The game thumbnails on the page are not retrievable from the archive; no other page for either game was found (Google searches by title return only Chocobo Panic, an unrelated iPad game)
- https://www.jp.square-enix.com/announce/semobile/ -- terminated* for the four Square Enix Mobile games (Square Enix's end-of-service notice for 「スクエニモバイル」, the live page; text pasted by user, identical to the capture of 2018-04-02, https://web.archive.org/web/20180402064630/http://www.square-enix.co.jp/mobile/sem/) -- accessed 2026-10-24
  - Square Enix Mobile ended all services on 2018-03-31; from 2018-04-01 its member data and installed apps are unusable
