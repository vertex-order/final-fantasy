## Regenerating components.js

`components.js` (next to `page.dc.html` and the sibling `*.dc.html` files)
is a **derived build artifact** — it inlines every sibling `*.dc.html`
component so `page.dc.html` also works opened straight off disk (`file://`),
where the runtime's `fetch()` is blocked. The `*.dc.html` files are the
single source of truth. Never hand-edit `components.js`. Regenerate it
whenever a sibling `*.dc.html` (anything except `page.dc.html`) is added,
changed, or removed.

You are in one of two environments:

**1. Full repo checkout** (has `scripts/`, `justfile`, `.githooks/`) —
regenerate by running the script:

```sh
just build            # or: just bundle-components
python3 scripts/bundle-components.py   # same thing, if `just` isn't installed
```

The pre-commit hook also does it automatically. Human contributors: see
`CONTRIBUTING.md`.

**2. Design tool / flat working directory** (just the `site/` files pulled
in as your root, plus this `CLAUDE.md`; no `scripts/`, no shell) —
reproduce the script's exact output by hand so it stays diff-clean against
the repo. Read every sibling `*.dc.html` except `page.dc.html`, then
overwrite `components.js` with:

```js
// AUTO-GENERATED by scripts/bundle-components.py — do not edit by hand.
// Inlines sibling *.dc.html components so <dc-import> resolves without a
// fetch(), which browsers block on file:// origins. Regenerated by the
// pre-commit hook and `just build`.
(function () {
  var C = {
  "./ComponentA.dc.html": "<full source of ComponentA.dc.html as a JSON string>",
  "./ComponentB.dc.html": "<full source of ComponentB.dc.html as a JSON string>"
  };
  window.__resourceBlobs = window.__resourceBlobs || {};
  for (var k in C) {
    if (!window.__resourceBlobs[k]) {
      window.__resourceBlobs[k] = new Blob([C[k]], { type: "text/html" });
    }
  }
})();
```

Rules for the by-hand version:

- One `C` entry per sibling `*.dc.html` file, **excluding `page.dc.html`**,
  in sorted filename order.
- Key is `"./" + filename`. Value is the file's full source,
  JSON-stringified (this is what `json.dumps(..., indent=2)` produces —
  2-space indented, `ensure_ascii=False`).
- Keep the IIFE + `var C` + loop shape and the `window.__resourceBlobs`
  global exactly. `support.js` reads that global; a different name or shape
  silently no-ops.
- The header comment at the top of the current `components.js` is the
  authoritative spec — match it.
