# Wiki corrections

This list tracks places where a wiki page (or another community-edited
catalog) disagrees with the evidence we found while researching an entry.
Our entries follow the better-sourced value; this file records the wiki's
value, ours, and why, so the corrections can be reported upstream.

- One item per wiki page and fact.
- Each item gives the page URL, the wrong or missing value, the corrected
  value, our source document (which holds the full evidence), and a
  one-line reason.
- **Confirmed:** we checked it against a primary or publisher record.
  **Candidate:** it looks wrong but is not settled; do not report it yet.
- Add an item whenever a sources file records that a wiki "is wrong".
- How to maintain this file: [sources.md](sources.md), section "Wiki corrections".
