# Final Fantasy Vertex Order

A recommended play order for the Final Fantasy franchise. Static site,
deployed to GitHub Pages — push to `main` auto-deploys via GitHub Actions.

Site source lives in [`site/`](site/). It's plain HTML/CSS/JS: open
`site/page.dc.html` in a browser and it runs.
